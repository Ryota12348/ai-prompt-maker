# ai-prompt-maker

# プロンプトビルダー

プリセットとタグを選ぶだけで、画像生成用のプロンプト（カンマ区切りのタグ文字列）を作るウェブツールです。もともとPythonのCLIツールだったものを、HTML・CSS・JavaScriptに移したものです。

## 機能

- **プリセット選択**：複数選択できます。プリセットに `show_categories` があると、表示するカテゴリがそれだけに絞られます。
- **カテゴリ別のタグ選択**：タグをタップして選びます。もう一度タップすると解除されます。
- **自由入力**：カンマ（`,` または `、`）区切りで入力できます。新しいタグはそのカテゴリに追加され、そのまま選択されます。
- **プロンプト出力**：選んだタグを重複なしで画面下部に表示します。順番は「プリセットのタグ → カテゴリ順のタグ」です。
- **コピー・保存**：クリップボードへのコピー、履歴への保存（最新50件）、`日時-prompt.txt` のダウンロードができます。

## ファイル構成

```
prompt-builder/
├ index.html     画面
├ style.css      見た目
├ app.js         動作
├ tags.json      カテゴリごとのタグ一覧
└ presets.json   プリセット一覧
```

## 使い方

ブラウザの制限により、`index.html` をダブルクリックして開く（`file://`）と、JSONを自動では読み込めません。その場合は、画面に出るボタンから `tags.json` と `presets.json` を2つ同時に選べば、そのまま使えます（毎回選ぶ必要があります）。毎回選ぶのが面倒なときは、Webサーバー経由で開いてください。

```bash
cd prompt-builder
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。GitHub PagesやNetlifyなどの静的ホスティングに、このフォルダごと置いても動きます。

## データ形式

### tags.json

カテゴリ名をキーにして、タグの配列を入れます。

```json
{
  "品質": ["masterpiece", "best quality"],
  "背景": ["simple background", "outdoors"]
}
```

### presets.json

値は2通りの書き方ができます。

```json
{
  "高品質": ["masterpiece", "best quality", "highly detailed"],
  "人物だけ": {
    "tags": ["masterpiece", "best quality"],
    "show_categories": ["キャラクター", "服装"]
  }
}
```

- 配列：そのタグをまとめて追加します。
- オブジェクト：`tags` のタグを追加し、`show_categories` に書いたカテゴリだけを表示します（省略可）。

## 自由入力したタグの保存について

ブラウザは同じフォルダのファイルに直接書き込めません。そのため、自由入力で追加したタグは **ブラウザ（localStorage）** に保存され、次回の起動時に `tags.json` へ重ねて表示されます。

`tags.json` 自体に反映したい場合は、次の手順で行います。

1. 画面の「タグの管理」を開き、「tags.json を書き出す」を押します。
2. ダウンロードされたファイルで、フォルダ内の `tags.json` を置き換えます。

追加タグを消したい場合は、同じ場所の「追加したタグを消す」を押します。

## Python版との違い

| Python版 | ウェブ版 |
| --- | --- |
| 番号入力、範囲指定（`1-3`） | タグをタップして選択 |
| `tags.json` を自動で上書き | ブラウザに保存し、必要に応じて書き出し |
| `logs/` フォルダにテキスト保存 | 履歴への保存と、txtのダウンロード |

## 注意

画像生成時に、各要素の直前に色情報を追加するなど、最終確認をすることをおすすめします。
